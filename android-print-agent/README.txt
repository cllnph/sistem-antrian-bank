PENGHUBUNG CETAK ANDROID - BANK DP TASPEN

1. Pada menu Penghubung Cetak Cabang, unduh dan pasang Aplikasi Android (APK).
2. Unduh Paket Android untuk kantor yang benar. Paket berlaku 15 menit.
3. Hubungkan Android dan Epson L6290 ke jaringan Wi-Fi yang sama. Siapkan A4.
4. Buka aplikasi Cetak Antrean Bank DP Taspen, lalu Impor Paket Android (ZIP ini).
5. Isi alamat IP printer dari layar/pengaturan jaringan L6290, lalu Periksa Printer & Pasangkan.
   Untuk IPPS, konfirmasikan sertifikat printer setelah mencocokkan alamat/sidik jarinya dengan petugas jaringan.
6. Tekan Jalankan Penghubung. Paket admin terbaru mengaktifkan penghubung setelah printer siap.
7. Tekan Buka Kiosk Cabang. Browser dipasangkan dengan kode sementara lalu membuka kiosk; Ambil Tiket dicetak melalui penghubung Android yang benar.

L6290 menggunakan Wi-Fi/IPP. Bluetooth tidak tersedia pada model ini.
Android minimal 8.0. Printer harus menawarkan PWG Raster sRGB atau PDF melalui IPP.
Format cetak pengujian: satu halaman A4, isi tiket tetap pada ukuran aslinya, satu salinan.
Tidak ada fallback ke Print/PDF Android. Tidak perlu Epson Smart Panel untuk jalur ini.
Printer, Android, dan aplikasi pusat harus tetap dapat dijangkau. Server pusat tetap diperlukan.
Setelah restart Android, buka aplikasi dan Jalankan Penghubung lagi. Izinkan notifikasinya.
Jika Android menghentikan aplikasi karena hemat baterai, buka kembali dan periksa status Siap.
Satu cabang dapat memiliki beberapa penghubung. Setiap browser dipasangkan ke penghubung yang membuka kiosk tersebut. Memasang ulang penghubung yang sama mengganti akses lamanya.
Jangan membagikan ZIP ini. Kunci pemasangan hanya berlaku sekali dan 15 menit.
Jika hasil cetak tidak pasti, periksa kertas sebelum memakai Cetak Ulang pada nomor yang sama.
